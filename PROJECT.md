# Project
Slewn Air V20: a Eurorack module (22 HP, Intellijel 1U) built around a Radxa ZERO 3W, with a display and a
rotary encoder on a separate UI board.

## Boards
| Board | Folder | Job |
|---|---|---|
| MAIN | `hw/main` | Rack power (+12 V) to 5 V for the Radxa, Radxa header J1, UI connector J2, expansion header J4 |
| UI | `hw/ui` | Display J102 and encoder ENC101, connector J101 that mates 1:1 with MAIN J2 |

## Build level
**DIY** (see the complexity-level skills): builders who follow the build notes. No protection on internal
nets; external protection only against mistakes the instructions cannot prevent (reversed rack ribbon → Q1,
short on the rack bus → F1). Build and bring-up steps are on the MAIN schematic.

## Parts that must not change
- J1, J2, J3 footprints on MAIN stay exactly as in commit `018b1a3` (only the 3D model path may differ).
  Guarded by `test_connectors_match_base_commit` in `scripts/main_sch/tests/test_fpcheck.py`.
- UI PCB: J101, J102, ENC101 (position, rotation, side, footprint) and the board outline (84.2 × 21.0 mm)
  stay exactly as in commit `018b1a3`. Guarded by `test_pcb_mechanics_match_release` in
  `scripts/ui_sch/tests/test_ui_install.py`.
- U1 is the Waveshare DC5-36-TO-DC3V3-5 module, SMD version without headers (Waveshare SKU 29035): its
  footprint has flat SMD pads. Set to 5 V. Bought from Waveshare, not LCSC.
- DNP by design: C2, C4 (the U1 module has its own capacitors), R2, R3 (optional I2C5 pull-ups).
- UI, DNP by design: C104 (the TB147 display module has its own LDO and capacitors), R104 (backlight
  pull-down; the RK3566 pulls LCD_BL down from reset), C103 (ENC_SW debounced in software). The 0R link in the
  display's 5 V feed (old R104) is removed and the old R105 is now R104. The UI sheet is generated by
  `scripts/ui_sch/ui_layout.py`.

## Pin map
`docs/hardware/slewn-v20-pinout.html` is the reference for J1, J2/J101 and J4. The MAIN schematic is
generated by `scripts/main_sch/layout.py`; `test_header_pinout` holds the approved table.
- J2/J101 pins 1–8 follow the display's pin order, 9–14 are the encoder.
- J4 (2×17) brings out every Radxa pin MAIN does not use; only J1·26 (NC) is unconnected.

## Electrical rules
- J4 budget: 5 V max 1 A; 3V3 comes from the Radxa, small loads only.
- SPI3 is shared: the display uses CS0 (J1·24), a device on J4 uses CS1 (J1·22, `cs-gpios`).
- UART2 on J4 is the Radxa boot console (1 500 000 baud): USB-UART cable only.

## Workflow
- Edit the MAIN schematic through the generator (`python3 scripts/main_sch/layout.py`), then copy
  `out/main_sch/full/Slewn_V20_MAIN.kicad_sch` to `hw/main/` only when no `.kicad_sch.lck` is present.
- The MAIN PCB is not synced with the schematic yet; that is a deliberate, separate step.
- UI PCB: synced to the schematic on 2026-11-21 with `scripts/ui_pcb/sync_from_sch.py` (J101, J102, ENC101
  and the outline untouched, 0R link removed, R105 renamed R104, all tracks removed, R/C left in place).
  Routing is next.
