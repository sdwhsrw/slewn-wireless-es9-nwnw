# Slewn_MAIN library — sources

Library for the redrawn MAIN schematic (`../Slewn_V20_MAIN.kicad_sch`). Registered in the
project's `sym-lib-table` and `fp-lib-table` as `Slewn_MAIN`. Rebuild the symbols with
`python3 scripts/main_sch/build_symbols.py` from the board root.

Every other symbol and footprint the schematic uses comes straight from the KiCad 10.0.8 libraries.

## Symbols (`Slewn_MAIN.kicad_sym`)

| Symbol | Source | Edits |
|---|---|---|
| `AO4407A` | LCSC C16072 (Alpha & Omega), EasyEDA symbol imported with easyeda2kicad 1.0.1 | Pin numbers and names kept (S=1–3, G=4, D=5–8). Redrawn on the KiCad `Device:Q_PMOS` body with the S and D pins stacked. Pin types set. |
| `TPS25940LRVCR` | LCSC C2867756 (Texas Instruments), EasyEDA symbol imported with easyeda2kicad 1.0.1 | Pin numbers and names kept. Pin 14 renamed EN → EN/UVLO (TI datasheet name). Pins rearranged: IN on the left, OUT on the right, set-up pins and GND (16 with EP 21 stacked) at the bottom. Pin types set from the TI datasheet. |
| `Waveshare_DC536_5V` | Drawn for this project | Waveshare DC5-36 to 3.3/5 V module, set to 5 V. Pin numbers I1–I4 / O1–O6 match the `U1_Waveshare33x16` pads. |

The raw imports are kept in `lcsc_import/` (`lcsc.kicad_sym`, `lcsc.pretty/`) for reference. Their footprints are not
used (see below). Their 3D models were not kept: re-download them with
`easyeda2kicad --lcsc_id=<code> --3d` if needed.

## Footprints (`Slewn_MAIN.pretty`)

These footprints are copied unchanged from the project's earlier `Libs/` folder, apart from the 3D
model path, which now points at `library/3dmodels/`. No library footprint has identical pads:

| Footprint | Ref | Why it is kept |
|---|---|---|
| `J1_GPIO40` | J1 | The stock `PinHeader_2x20_P2.54mm_Vertical` is the same pattern rotated 90°. |
| `J3_IDC10` | J3 | Deliberate 1.1 mm drill / 1.9 mm pad, against the stock IDC footprint's 1.0 / 1.7 mm. |
| `KH-2.54PH90-1X14P-L13.8` | J2 | The LCSC C2905430 footprint is rotated with a 1.2 mm drill. The stock 1×14 has a 1.0 mm drill against 1.02 mm. |
| `WE_LHMI_74437324022` | L1 | The LCSC C2651177 footprint has 2.3 mm pads against 2.4 mm. KiCad has no WE-LHMI footprint. |
| `U1_Waveshare33x16` | U1 | Module footprint; no library has it. |

## 3D models (`3dmodels/`)

`IDC-Header_2x05_P2.54mm_Vertical.step` comes from KiCad 10.0.8 (kicad-packages3D) and
`KH-2.54PH90-1X14P-L13.8.step` was generated by the project. Both were copied from `Libs/models3d/`.
